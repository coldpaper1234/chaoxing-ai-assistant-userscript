# 学习通 AI 助手 · Clawd 移植源码

`chaoxing-ai-assistant-clawd.user.js` 为当前 1.33.16 完整主脚本，直接替换现有学习通 AI 助手即可。小精灵位于面板上沿，主脚本为其及堆叠预留顶部空间。不要同时启用 `chaoxing-clawd.user.js` 配套版。

已移入普通 Clawd 的动作帧、眨眼、点击、摸头、长按、拖拽、抛掷物理、动作冷却、待机/睡眠、输入节奏和三只小 Clawd 的碰撞堆叠。

来源为保留在 `upstream/` 的 Claude Web 2.0.161 快照，作者署名 lulu，原项目：https://github.com/claudenoshujin/claude-web 。这些是第三方主题的互动实现，不称为 Anthropic 官方动画。

面板、输入和任务状态通过 `adapter.js` 接入；收起面板、隐藏页面或离开页面时释放实例，恢复可见及 `pageshow` 时重新挂载。互动模块不调用模型接口，不点击题目，不提交测验，不写入主脚本设置。小精灵位置继续使用独立本地键 `cx-ai-clawd-pile-v3`，只存位置偏好，不包含题目、答案、账号或密钥；题目导出格式不变。没有接入酒馆主题、聊天管理或万圣节服装。

构建命令：`node build.mjs <主脚本路径>`。生成完整合并版及独立配套版；已有嵌入标记时替换该部分，标记异常则停止，不会重复叠加。完整主脚本在维护仓库根目录发布，源码同步到 `sources/clawd/`；正常维护更新会保留小精灵。

只进行了静态源码审查及必要构建，没有运行语法检查、自动测试或浏览器实测。手机拖拽、输入法、收起恢复与跨页行为仍需实际验收。
