# 学习通 AI 助手 · Clawd 移植源码

`chaoxing-ai-assistant-clawd.user.js` 为当前 1.33.20 完整主脚本，直接替换现有学习通 AI 助手即可。小精灵位于面板上沿，主脚本为其及堆叠预留顶部空间。不要同时启用 `chaoxing-clawd.user.js` 配套版。

已移入普通 Clawd 的动作帧、眨眼、点击、摸头、长按、拖拽、抛掷物理、动作冷却、待机/睡眠、输入节奏和三只小 Clawd 的碰撞堆叠。

面板顶栏“装扮”可连续添加普通、牛仔、墨镜、巫师小精灵，或删除选中的小精灵；不再固定为原来的三只小精灵。小精灵可全部删除，大 Clawd 作为主精灵单独保留。每只独立配置帽子、眼镜、饰品及身体、帽子、饰品颜色；增减、换装、恢复操作都在点击“应用装扮与数量”后生效。恢复默认装扮保留现有数量；“恢复默认数量”单独回到原来的三只。不支持图片上传或远程素材。

装扮沿用独立偏好键 `cx_clawd_wardrobe_v1`，主脚本存于油猴本机设置；独立配套版使用本地存储。schemaVersion 2 将 roster、nextId、动态 pets、revision、mode 放在同一条记录，数量和装扮一次保存并回读确认；旧版 schemaVersion 1 读取时迁移为原三只名单，保留既有装扮，首次应用才写入新版。未知版本、未知字段、重复ID、缺失关联停止写入；跨页面修改冲突不覆盖，保存失败重新读取实际记录并提示核对。不含题目、答案、API 或仓库凭据，题目导出和暂存格式不变；装扮/数量不混入题目导出，油猴设置导出由脚本管理器提供。旧版脚本不能编辑新格式，必须同步更新所有页面。

`wardrobe.js` 管理名单与装扮；`pile-roster.mjs` 为构建期转换，保留 `upstream/` 原文件。动态名单使用稳定 ID，删除后停止该只的计时器、指针回调和动画，移除失效的堆叠支撑；刷新读取位置时过滤缺失ID和循环支撑。恢复装扮不重置数量、API、题目记录或位置；位置仍独立使用既有偏好键，位置偏好写入不等于装扮记录的持久化确认。

来源为保留在 `upstream/` 的 Claude Web 2.0.161 快照，作者署名 lulu，原项目：https://github.com/claudenoshujin/claude-web 。这些是第三方主题的互动实现，不称为 Anthropic 官方动画。

面板、输入和任务状态通过 `adapter.js` 接入；同时识别普通面板和原生移动后的题目面板，沿可访问的祖先页面重新绑定所在文档。收起面板、隐藏页面或离开页面时释放实例，重新打开及 `pageshow` 时挂载。互动模块不调用模型接口，不点击题目，不提交测验，不写入主脚本设置。小精灵位置继续使用独立本地键 `cx-ai-clawd-pile-v3`，只存位置偏好，不包含题目、答案、账号或密钥；题目导出格式不变。没有接入酒馆主题、聊天管理或万圣节服装。

构建命令：`node build.mjs <主脚本路径>`。生成完整合并版及独立配套版；已有嵌入标记时替换该部分，标记异常则停止，不会重复叠加。完整主脚本在维护仓库根目录发布，源码同步到 `sources/clawd/`；正常维护更新会保留小精灵。

只进行了静态源码审查及必要构建，没有运行语法检查、自动测试或浏览器实测。手机拖拽、输入法、收起恢复与跨页行为仍需实际验收。
